# React GitHub Profile Finder

A simple and responsive GitHub Profile Finder built using React that allows users to search for any GitHub user's profile. This project demonstrates API integration, state management, event handling, error handling, and component-based architecture.

## Features

* Search GitHub users by username
* Display profile picture
* Show name and username
* Display bio
* Show followers, following, and public repositories
* Direct link to GitHub profile
* Responsive user interface
* Error handling for invalid usernames

## Technologies Used

* React
* JavaScript (ES6+)
* CSS
* Vite
* GitHub REST API

## Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/react-github-profile-finder.git
```

2. Navigate to the project directory:

```bash
cd react-github-profile-finder
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```
